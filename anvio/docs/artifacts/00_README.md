This directory contains information about anvi'o artifacts.

A complete list of artifacts is listed in `anvio/programsdata.py`.
You can also access to the list of artifacts programmatically this way:

```
python -c 'import anvio.programsdata; print(anvio.programsdata.ANVIO_ARTIFACTS);'
```

Information in this directory is compiled into help text shown in the following URL:

http://merenlab.org/software/anvio/help/
