This is a local copy of NCBI's [AMRFinderPlus](https://github.com/ncbi/amr/wiki) database, which describes antimicrobial resistance genes, stress response genes, and virulence genes.

To set it up on your computer you need to run the program %(anvi-setup-amrfinder)s, and it is required to run %(anvi-run-amrfinder)s.
